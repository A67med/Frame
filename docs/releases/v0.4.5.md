# Frame V0.4.5

## Changes

### Fixed

- Replaced Harbor loading artwork with the existing Frame mark in shared loading states, Big Picture startup, mobile setup and addon installation.
- Prevented P2P, watch-party and live recovery timers from replacing a paused playback session.
- Cleaned up native window listeners when the player closes during asynchronous registration.
- Fixed local video files being ignored on startup because the event arrived before the player subscribed.

### Restored

- Digital Releases now discovers and verifies regional TMDB digital release dates, with month selection, pagination, deduplication, caching and retry feedback.
- Updates & backup is grouped under System, with release history explicitly targeting A67med/Frame and clearer guidance before downloading older installers.

### Improved

- Backup export leaves credential-bearing sections unselected by default. You can explicitly include them using the existing encryption and consent controls.
- Internal ranking and installer-recovery crates now live under `crates/`. The macOS virtual microphone source is preserved under `native/macos/virtual-mic/`.
- Application lifecycle modules, compatibility documentation and repository hygiene checks are organized around Frame while preserving saved data and legacy identifiers.

### Notes

- Digital dates reflect TMDB's records for the selected country. Missing records are not replaced with theatrical dates or another country's dates; future dates can change.
- Recovery regression tests cover pauses of 10, 20, 30, 60 and 120 seconds. The [engineering report](v0.4.5-engineering.md) distinguishes those tests from native playback observations and records outstanding release checks.
- Existing themes, the application identifier and updater signing key are retained. Export a backup before downgrading; older builds may not understand newer data.
