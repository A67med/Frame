Frame 0.4.0 introduces **Theme Studio reinvented** and a collection of seven visual themes for the redesigned desktop.

### Highlights

- **Default keeps the Frame layout:** opening Default in Theme Studio no longer reverts the app to the former Harbor-style layout. The same layout persists in preview, saved themes and custom copies.
- **Seven visual identities:** Default, Noir Cinema, Aurora, Minimal Frost, Editorial, OLED Black and Retro Cinema, each with its own typography, spacing, color and surface treatment.
- **More control:** edit typography, content spacing, corner radius, solid/glass/gradient surfaces, elevation, navigation and legacy styling through bounded design controls.
- **More dependable editing:** searchable preset gallery, faithful live previews, reset, undo/redo, durable saving, editing existing custom themes without duplicates, and **Save as a new theme**.
- **Backwards compatible:** Stremio, Royal, Velvet and existing custom layouts are preserved. Converting a legacy theme to Frame requires an explicit choice, and a converted copy can be saved separately.
- **Import and export:** normalized design settings round-trip through JSON and `.framestyle` exports.

### Verification

2,564 automated tests passed (one skipped). TypeScript, changed-file lint and format checks, Windows NSIS packaging and a production-browser matrix across all seven themes passed. Browser checks included settings, library pages, overlays, persistence, imports/exports and HTML5 playback.

Native mpv playback, physical multi-monitor DPI transitions, authenticated provider integrations and installed-upgrade paths were not rechecked for this change. Nine existing settings-validator failures and prior Rust warnings remain.
