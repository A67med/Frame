## Preserved interfaces

- Custom/imported themes and Royal retain the old screen architecture. Runtime
  switching verifies that the new desktop marker is removed, and regression
  tests cover the opt-in decision and preview/child-profile exceptions.
- Big Picture, PiP, modal/HDR overlays, remote/mobile surfaces and installer
  auxiliary windows retain their purpose-specific layouts. Their native window
  behavior has not been visually revalidated in this browser pass.
- Stable `REMOVED_PAGES` already redirects music, games, anime, live TV/VOD,
  sports/matches, manga, ebooks, calendar, kids and social frames to Home. They
  are not active desktop pages in this branch and remain excluded.

## Review limits

Populated TMDB-driven sections, a large synchronized library, real downloads,
authenticated actions, extension source selection, custom player layouts and
native fullscreen/window controls need a configured Windows profile. Their
existing implementation and regression tests were retained; this report does
not claim that browser screenshots exercise those integrations.
