# Frame v0.3.0 UI migration

This is development work on `feature/v0.3.0-interface-reinvention`, based on
stable `271b08ea`. The application version remains **0.2.1**. Nothing is merged,
tagged, or released.

## Navigation and composition

- Default and AMOLED now have a 96px labelled navigation rail and a fixed 64px
  command bar. The profile moves to the command bar; Settings keeps the app rail.
  Collapsing the rail still uses the existing preference. Destinations still use
  the existing view stack and customization controls.
- Back and Forward share the command bar and use the stack's existing capability
  flags. Native window buttons, drag handlers, parental gates and configured
  shortcuts retain their existing implementations.
- Home introduces an editorial heading, an adjacent numbered feature index,
  a compact metadata-setup notice and a ruled Continue Watching region. User
  ordering, visibility and hero-source preferences remain authoritative.
- Discover pairs a lead image with a reading column containing title, rating,
  synopsis and expandable stills. Catalog and surprise actions form a separate
  exploration band. Its content builder and personalization are unchanged.
- Movie and TV details replace the minimum-640px backdrop with a content-sized
  dossier. Title, metadata, actions and synopsis occupy the reading column;
  backdrop, poster and logo occupy the artwork column. Episodes and credits
  follow immediately. Existing action overflow and page customization remain.
- Episode details use the same dossier, retaining spoiler blur/reveal controls.
- Library moves its collection tabs into a persistent working navigator. Results,
  filters and optional featured content occupy the adjacent workspace. Existing
  virtualized grids and local/provider membership logic are retained.
- Settings separates category selection from the page list. The list shows the
  selected category; search still searches every category and uses existing
  anchor/tab navigation. Small viewports retain the Browse pages control.
- Search has a defined heading and a wider query/results workspace, with a
  separate discovery layout in the empty-query state. Query engine, result
  grouping and keyboard activation are unchanged.
- Radar gains a section index when its data source is configured. Digital
  Releases remains an unavailable-integration notice. Following, catalogs,
  collections, downloads and other active views share the new page foundations.

## Shared presentation

New modules are `PageHeading`, `HistoryControls`, and `useCinematicDesktop`.
The latter opts built-in presets into the new presentation without modifying
theme settings. Existing UI primitives continue to own behavior.

The stylesheet is split into foundations/shell, discovery/details, workspaces,
and overlays. Its additive tokens are:

| Token                 | Purpose/default                                        |
| --------------------- | ------------------------------------------------------ |
| `--frame-rail`        | 96px rail; 64px collapsed; 72px narrow                 |
| `--frame-command`     | 64px command bar; 108px with existing hybrid title bar |
| `--frame-gutter`      | Responsive 24–64px page gutter                         |
| `--frame-section-gap` | 40px section rhythm                                    |
| `--frame-content-max` | 1840px reading/content ceiling                         |
| `--frame-radius`      | 8px shared panel corners                               |
| `--frame-rule`        | Existing theme edge color                              |
| `--frame-panel`       | Existing surface/canvas color mix                      |
| `--frame-display`     | Fraunces/Iowan/Georgia display stack                   |

The player retains its configurable control slots and all callbacks. The visual
layer now distinguishes header, timeline and transport, with a stronger bottom
scrim and consistent spacing. No playback bridge or native code changes.

Dialogs, context/profile menus, sign-in and onboarding use shared surface rules.
Onboarding stays above the new chrome and scrolls at small heights. Sign-in is
height-bounded. Profile menus dismiss with Escape and restore trigger focus.

Hero rotation pauses during focus and respects reduced motion. Inactive hero
slides are inert. New focus outlines use the existing theme accent. No new
animation or component dependency was added.

## Compatibility and deliberate retention

- Imported `user:*` themes, the custom preset, other built-in themes and theme
  previews keep their authored architecture. Child-profile presentation and
  Big Picture retain their separate input/layout systems.
- `Default.framestyle`, theme IDs, existing `harbor-*` selectors, storage keys,
  layout IDs, IPC and provider contracts are unchanged. New hooks are additive.
- Six UI strings have English catalog entries and fallback values for other
  locales. Human translations remain outstanding; existing translations win.
- Authentication forms, stream ranking/selection, settings controls, player
  layout customization, lists, virtualized rows and dialogs retain their working
  handlers. No components or features were deleted.
- Already-disabled music, gaming, anime, social, live TV, sports, manga, ebooks
  and calendar routes were not re-enabled. Remote/mobile and native auxiliary
  windows are not part of this desktop composition.
